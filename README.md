# 🎮 Trash Emperors - Landing Page

Uma landing page moderna, interativa e gamificada para o jogo **Trash Emperors**, um jogo educativo estilo arcade que ensina reciclagem e separação de lixo.

## 🌟 Características

- ✨ **Design Moderno**: Interface responsiva com gradientes e animações fluidas
- 🎮 **Elementos Gamificados**: Animações interativas que criam uma experiência envolvente
- 📱 **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- 🚀 **Performance Otimizada**: Construído com React e Vite para carregamento rápido
- ♿ **Acessível**: Segue boas práticas de acessibilidade web

## 🎯 Seções da Landing Page

1. **Header Sticky** - Navegação flutuante com logo animado
2. **Hero Section** - Apresentação impactante com animação do caminhão de lixo
3. **Features** - Apresentação dos 5 tipos de resíduos (papel, vidro, metal, plástico, orgânico)
4. **Gameplay** - Tutorial sobre como jogar com 4 passos simples
5. **Download** - Opções de download para múltiplas plataformas
6. **Footer** - Links, contato e informações legais

## 🛠️ Tecnologias Utilizadas

- **React** 19.2.5
- **Vite** 8.0.10
- **CSS3** - Animações, Gradientes, Grid e Flexbox
- **JavaScript ES6+**

## 🚀 Como Começar

### Instalação

```bash
# Clonar o repositório
git clone <seu-repositorio>

# Entrar no diretório
cd trashEmperors

# Instalar dependências
npm install
```

### Desenvolvimento

```bash
# Iniciar servidor de desenvolvimento
npm run dev
```

A landing page estará disponível em `http://localhost:5173`

### Build para Produção

```bash
# Compilar para produção
npm run build

# Visualizar build
npm run preview
```
